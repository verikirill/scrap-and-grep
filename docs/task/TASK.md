# Задание полуфинала

Текст задания организаторов хакатона «ИИ-ассистенты для энергетики», как он дан командам. Датасет с примерами лежит рядом: [dataset_v4.0.xlsx](dataset_v4.0.xlsx) и его текстовая копия [dataset_v4.0.md](dataset_v4.0.md). Как решение отвечает на каждое требование, сказано в README в разделе «Что реализовано».

## Задача

Разработать ИИ-помощника, который отбирает релевантные публикации и формирует тематический дайджест.

Специалисты по ИТ и ИБ регулярно просматривают новости из разных источников, выбирают полезные публикации и группируют их по темам. Подготовка такой подборки требует времени и учёта профессиональных интересов читателя.

## Требования к прототипу

В полуфинале прототип должен:

- получать публикации из выбранных командой источников;
- отбирать материалы по заданным интересам пользователя;
- группировать выбранные публикации по темам и сохранять ссылки на источники;
- формировать дайджест в Markdown или DOCX.

## Использование моделей

В полуфинале можно использовать gpt-oss-120b, Alice AI ART, Qwen3.6 35B-A3B либо модели сопоставимой мощности. Команда выбирает модели под функции своего решения. Использовать все перечисленные модели не требуется.

Допускается подключение моделей через API. Предусмотрите возможность заменить модель без существенной переработки решения. Основной сценарий должен сохраняться при переходе на другую модель с необходимыми для задачи возможностями.

Использование более мощной модели само по себе не даёт дополнительных баллов. При оценке технической реализации учитываются архитектура, работа с данными и контекстом, промптинг, применение инструментов, проверка результатов и устойчивость решения.

В финале будут использоваться модели Яндекса.

## Результат полуфинала

Рабочий прототип, который обрабатывает набор публикаций и создаёт дайджест. Команда показывает исходные материалы, результат отбора и изменение подборки при изменении интересов пользователя.

## Что нужно сдать

- Рабочий прототип решения.
- Исходный код и инструкцию запуска.
- Примеры входных данных и полученных результатов.
- Краткое описание реализованных возможностей и ограничений.

## Критерии оценки

- Репрезентативность предоставленных материалов: 0-10 баллов.
- Качество и новизна технической реализации: 0-10 баллов.
- Бизнес-ориентированность решения: 0-10 баллов.

Максимальная оценка: 30 баллов.
