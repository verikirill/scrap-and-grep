# Задание финала

Разработать ИИ-помощника, который отбирает релевантные публикации и формирует тематический дайджест.

Специалисты по ИТ и ИБ регулярно просматривают новости из разных источников, выбирают полезные публикации и группируют их по темам. Подготовка такой подборки требует времени и учёта профессиональных интересов читателя.

## Требования к прототипу

В финале прототип должен:

- получать публикации из выбранных командой источников;
- отбирать материалы по заданным интересам пользователя;
- группировать выбранные публикации по темам и сохранять ссылки на источники;
- формировать дайджест в Markdown или DOCX.

## Использование моделей в финале

В финале решение должно использовать предоставленные организаторами модели Яндекса через Yandex AI Studio. Нужно предусмотреть возможность заменить модель без существенной переработки решения: основной сценарий должен сохраняться при переходе на другую модель с нужными возможностями.

При оценке технической реализации учитываются архитектура, работа с данными и контекстом, промптинг, применение инструментов, проверка результатов и устойчивость решения. Выбор более мощной модели сам по себе не даёт дополнительных баллов.

## Результат финала

Рабочий прототип, который обрабатывает набор публикаций и создаёт дайджест. Команда показывает исходные материалы, результат отбора и изменение подборки при изменении интересов пользователя.

## Критерии оценки финала

Максимум 9 баллов:

- соответствие подхода задаче - 0-3 балла;
- качество и полнота реализации - 0-3 балла;
- репрезентативность материалов и самой защиты - 0-3 балла.
