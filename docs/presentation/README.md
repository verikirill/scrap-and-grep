# Презентация

[scrapgrep.pdf](scrapgrep.pdf) - 18 слайдов 1920×1080 для защиты. Порядок такой: задача заказчика, решение, скорость, путь от уязвимости до исправления, исследование с аналитиком ИБ, цена выпуска у аналитика и у ассистента по ценам 2026 года с источниками, две аудитории, настройка под читателя, телефон, пространство компании, доставка, проверка специалистами, масштаб и надёжность, архитектура, качество и безопасность, внедрение, что посмотреть самому. Каждый факт стоит на одном слайде.

[scrapgrep.pptx](scrapgrep.pptx) - та же презентация для правки в PowerPoint. Весь текст лежит в обычных текстовых полях шрифтом Inter, как на сайте, и шрифт встроен в файл. Рамки ноутбука и телефона с экранами, кот и выноски - отдельные картинки, их можно двигать. Подложки карточек и графики лежат в фоне слайда.

Исходник - [slides.html](slides.html), обычная страница с цветами и шрифтами сайта: Inter и Inter Display (OFL, файлы в `fonts/`). Экраны сняты 21 октября 2026 года со стенда на моделях Yandex AI Studio и лежат в `img/shots/`, кот из сервиса - в `img/brand/`. Каждая цифра на слайдах взята из документов репозитория, источник подписан внизу слайда.

## Сборка

Нужны Node с пакетом `playwright-core` (путь к нему можно задать переменной `PLAYWRIGHT_CORE`), Chrome или Edge и `uv`. Для PPTX ещё нужен PowerPoint.

Сначала `build.cjs` печатает PDF и готовит всё для PPTX. Полупрозрачные подложки с размытием Chromium при печати не рисует, поэтому каждый слайд сначала снимается картинкой без текста, а PDF кладёт поверх неё живой текст: его можно выделить и найти поиском.

```bash
node docs/presentation/tools/build.cjs docs/presentation/slides.html tmp/deck docs/presentation/scrapgrep.pdf
```

Потом `build_pptx.py` (python-pptx) раскладывает фон, картинки и текстовые поля по слайдам, а `embed_fonts.ps1` открывает файл в PowerPoint, встраивает Inter и сохраняет. Шрифты подключаются только на время работы скрипта, в систему ничего не ставится. С ключом `-Png` скрипт заодно выгружает каждый слайд так, как его рисует PowerPoint.

```bash
uv run --no-project --with python-pptx python docs/presentation/tools/build_pptx.py tmp/deck tmp/deck/raw.pptx
powershell -File docs/presentation/tools/embed_fonts.ps1 -In tmp/deck/raw.pptx -Out docs/presentation/scrapgrep.pptx -Png tmp/deck/png
```
