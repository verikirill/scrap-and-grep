# Независимый экспертный аудит

Отбор ассистента вслепую оценил независимый эксперт - высококлассный аналитик ИБ. Это не замена итоговой разметке человеком: она по-прежнему входит в приёмку пилота ([human](../human/README.md)). Это второе мнение, которое показывает, где отбор держится, а где расходится с внешним взглядом.

## Кто и как размечал

- Эксперт: специалист по информационной безопасности и анализу данных, разметка 23 октября 2026 года. Выпуски собрал ассистент, эксперт оценивал их кандидатов независимо от него.
- Вслепую: эксперт видел только профиль читателя и 60 кандидатов в перемешанном порядке, как в файлах [human](../human/README.md). Оценок ассистента и состава выпуска он не видел.
- Текст: заголовок и первые 1000 знаков статьи из снимка [data/samples](../../../data/samples/articles.jsonl).
- Шкала, «обязательные» и приоритет - по той же инструкции, что для человека: [human/README.md](../human/README.md#как-размечать).

Файлы: [ics-security-engineer.csv](ics-security-engineer.csv) и [management-cybersecurity.csv](management-cybersecurity.csv). Метрики считает тот же скрипт, что посчитает итоговую разметку; слово «человек» в его выводе здесь означает эксперта:

```bash
uv run scripts/eval_selection.py score docs/eval/human/ics-security-engineer.digest.json docs/eval/second-human/ics-security-engineer.csv
uv run scripts/eval_selection.py score docs/eval/human/management-cybersecurity.digest.json docs/eval/second-human/management-cybersecurity.csv
```

## Результат

| Метрика | Специалист по ИБ АСУ ТП | Руководство и сотрудники |
|---|---|---|
| Точность: записей выпуска с оценкой 2-3 | 17 из 20 (85%) | 10 из 15 (67%) |
| Полнота «обязательных» | 8 из 9 (89%) | 5 из 6 (83%) |
| nDCG@20 порядка выпуска | 0,72 | 0,47 |
| Оценки совпали точно | 33 из 60 (55%) | 32 из 60 (53%) |
| Взвешенная каппа оценок | 0,75 | 0,48 |
| Приоритет атак и уязвимостей совпал | 15 из 16 (94%) | - |

Выпуск специалисту эксперт принимает: каппа 0,75 - существенное согласие, приоритет по правилу датасета совпал в 15 случаях из 16. Выпуск руководству слабее: треть записей эксперт считает необязательными для этого читателя.

## Где разошлись

Пропущенные «обязательные»:

- **Специалисту: FortiMail 0-day** (CVE-2026-104286, в CISA KEV с 1 октября, исправления нет). Эксперт поставил 1: «не относится к OT». Но в профиле есть интерес «Уязвимости и обновления безопасности» корпоративного ПО и сетевого оборудования, и почтовый шлюз под активной эксплуатацией - как раз он. Эксперт сузил профиль до АСУ ТП.
- **Руководству: утечка «Додо Пиццы»**, самая громкая российская утечка недели: в выпуске нет ни одной из четырёх публикаций о ней. Эксперт поставил 2, но запись не прошла в 15 мест выпуска.

Записи выпуска, которые эксперт считает необязательными (оценка 1):

- специалисту: практика аттестации по приказу ФСТЭК № 117 (он о ГИС, а не о КИИ), статья о приоритизации уязвимостей без конкретных CVE, обзор «долга безопасности» OT;
- руководству: та же статья о приказе № 117, уязвимости контроллеров Johnson Controls (технические детали для специалиста), утечка в Пентагоне, ограничения VPN на серверах, статья о защищённом хостинге.

Общая черта: ассистент охотно берёт аналитические статьи и регуляторику соседних областей, когда в теме нет свежего события. Что с этим делать, решит итоговая разметка человеком на пилоте: если человек согласится с экспертом, порог для записей без события стоит поднять.

## Ограничения

- Эксперт - внешний специалист: его контекст может отличаться от ежедневной работы целевого читателя.
- Эксперт видел заголовок и первые 1000 знаков, а не статью целиком; у части публикаций в снимке есть только заголовок и анонс.
- Одна неделя и два профиля.
