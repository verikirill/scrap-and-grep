## Как проверяли

- Дата проверки: 2026-10-23, 22:04-22:13 МСК.
- Инструмент: `curl -L` с User-Agent Chrome 129 для Windows и `Accept-Language: ru-RU`, по одному-три запроса на сайт с паузой 1 с. Смотрели код ответа, заголовки `Server` и `CF-Ray`, заголовок страницы, признаки проверки («Just a moment», `challenge-platform`, DDoS-Guard, Qrator, капча), ссылки `<link rel="alternate" type="application/rss+xml">` и даты в ленте.
- Запросы шли с адреса в Нидерландах (`ifconfig.co/country`, 2026-10-23 22:08 МСК). Российские госсайты могут отвечать иначе на российский адрес, поэтому таймаут ниже записан как факт об этом адресе, а не о сайте.
- Повторная проверка пробелов: 2026-10-23, 22:31-22:37 МСК, тем же curl, плюс WebFetch и web.archive.org там, где curl не прошёл. Адрес снова нидерландский (`ifconfig.co/country` в 22:31 МСК ответил `The Netherlands`), то есть российские сайты по-прежнему проверены не с российского адреса.
- Третья проверка: 2026-10-23, 22:53-22:55 МСК, тем же curl, после включения раздельного туннелирования VPN - российские сайты идут напрямую с российского адреса, зарубежные по-прежнему через Нидерланды (`ifconfig.co/country` в 22:53 ответил `The Netherlands`, это зарубежный сайт). Свой адрес для `.ru` отдельно не измеряли; признак смены маршрута - digital.gov.ru, который с нидерландского адреса не отвечал, теперь отдаёт HTTP 200. С российского адреса проверены digital.gov.ru (строка «Минцифры»), cert.gov.ru (`/rss/` - снова HTTP 404) и rkn.gov.ru (`/_services/rss/` - снова HTTP 200, 50 записей). Остальные сайты и regulation.gov.ru (его имя сейчас не резолвится) с российского адреса не перепроверяли.
- В «Свежесть» вписаны три последние даты из RSS или со страницы на момент проверки.
- Слово `captcha` в коде страницы само по себе не признак проверки: у habr.com это значок reCAPTCHA, у zmina.info - поле формы, у vg-news.ru - скрипт Yandex SmartCaptcha. Всё это ставится на формы, а сама страница пришла с нормальным содержимым.
