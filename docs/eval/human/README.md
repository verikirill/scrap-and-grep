# Разметка человеком: заменяет ли ассистент аналитика

Жюри проверяет гипотезу «ИИ-ассистент может заменить аналитика ИБ» в отборе и приоритизации новостей. Ответить на неё может только сравнение с человеком. Здесь лежит всё, чтобы его провести: что размечать, как и чем посчитать.

## Что размечать

Неделя снимка, 25 сентября - 2 октября 2026 года, два профиля:

| Файл для разметки | Выпуск ассистента | Профиль |
|---|---|---|
| [ics-security-engineer.csv](ics-security-engineer.csv) | [ics-security-engineer.digest.json](ics-security-engineer.digest.json) | Специалист по ИБ АСУ ТП |
| [management-cybersecurity.csv](management-cybersecurity.csv) | [management-cybersecurity.digest.json](management-cybersecurity.digest.json) | Руководство и сотрудники |

В каждом файле 60 кандидатов, которые поиск нашёл по интересам профиля: и те, что вошли в выпуск, и те, что нет. Порядок перемешан, оценки модели в файле нет: размечать надо вслепую, не открывая выпуск.

## Как размечать

Откройте файл в Excel или LibreOffice: кодировка UTF-8, разделитель - запятая. Для каждой строки откройте статью по ссылке и заполните колонки:

- `grade` - оценка по той же шкале, что у модели:
  - 0 - не относится к интересам читателя, реклама, вакансия, пересказ без фактов;
  - 1 - косвенно связана, читать необязательно; сюда же пресс-релизы о партнёрствах и наградах;
  - 2 - по теме интереса, стоит включить в выпуск;
  - 3 - прямо по интересу и требует внимания или действий.
- `must` - 1, если без этой новости выпуск для этого читателя неполон. Один сюжет часто стоит в нескольких строках из разных источников: `must` ставьте одной копии, самой полной, тогда сюжет войдёт в полноту один раз;
- `priority` - только в файле специалиста и только для атаки или уязвимости, по правилу датасета организаторов:
  - атака: `high` - на энергетику или промышленность РФ, `medium` - на другие отрасли РФ, `low` - за рубежом;
  - уязвимость: `high` - есть эксплойт или используется в атаках, `medium` - нет.

В `note` можно написать, почему. Засеките время на файл и запишите его, вместе с именем и опытом размечавшего, в первую строку `note`.

## Как посчитать

```bash
uv run scripts/eval_selection.py score docs/eval/human/ics-security-engineer.digest.json docs/eval/human/ics-security-engineer.csv
uv run scripts/eval_selection.py score docs/eval/human/management-cybersecurity.digest.json docs/eval/human/management-cybersecurity.csv
```

Скрипт печатает таблицу в Markdown:

- точность: доля записей выпуска, которым человек поставил 2 или 3;
- полнота: доля «обязательных» по мнению человека, которые вошли в выпуск;
- nDCG@20: насколько порядок выпуска совпадает с оценками человека;
- совпадение оценок модели и человека и взвешенная каппа;
- совпадение приоритетов атак и уязвимостей.

Шаблон для другой недели или профиля строится из выпуска, сохранённого через `GET /api/v1/digests/{id}`:

```bash
uv run scripts/eval_selection.py template digest.json docs/eval/human/<профиль>.csv
```

## Ассистент и аналитик

Аналитик ИБ собрал оба выпуска этой недели вручную. Время на выпуск, охват недели и разница в отборе - в [vs-analyst.md](../vs-analyst.md). Время ассистента записано в поле `stats.duration_seconds` выпуска: 70,5 с на выпуск специалисту и 14,7 с на выпуск руководству.

## Приёмка пилота

Этот комплект - процедура приёмки пилота ([BUSINESS](../../BUSINESS.md), «Пилот»): человек размечает кандидатов недели, скрипт из раздела «Как посчитать» даёт метрики. Файлы комплекта скрипт читает как есть, так что считать можно сразу после разметки.
