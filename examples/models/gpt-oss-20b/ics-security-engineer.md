# Иранская атака на водоснабжение и критические OT-уязвимости 2026

**Профиль:** Специалист по ИБ АСУ ТП (версия 1)  
**Период:** 25.09.2026 - 02.10.2026  
**Сформирован:** 02.10.2026 17:57 МСК

## Главное

- CyberAv3ngers использовали уязвимости PLC Unitronics для доступа к американским системам водоснабжения.
- Citrix NetScaler и Cisco Catalyst SD-WAN Manager раскрыли критические 0-day CVE-2026-88772 и CVE-2026-76504, позволяющие удалённо выполнить код с root-правами.
- D-Link, FortiMail и WSO2 API Manager также обнаружены критические уязвимости, открывающие RCE и обход аутентификации.
- Накопленный долг по OT-безопасности десятилетий усиливает риски для промышленной инфраструктуры.
- Необходимо срочно обновлять ПО, проводить аудит и внедрять многоуровневую защиту для АСУ ТП и диспетчерских центров.
