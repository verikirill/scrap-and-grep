### [Citrix NetScaler: две 0-day уязвимости (CVE-2026-88771, CVE-2026-88772) с удалённым выполнением кода](https://t.me/true_secator/8662)

Уязвимости позволяют без аутентификации выполнить произвольный код, установить веб-оболочки, получить root-доступ и украсть учётные данные в Citrix NetScaler ADC/Gateway.

- **Затронуто:** Citrix NetScaler ADC и Gateway всех версий, уязвимы CVE-2026-88771 (RCE без аутентификации) и CVE-2026-88772 (memory-overflow, RCE/DoS при включённом DTLS).

- **Временные меры:** Проверить наличие файлов ctxs.receiver, записей Alias/AliasMatch в httpd.conf, прав доступа к /bin/sh и блокировать соединения с подозрительным IP (149.104.78.141).
- **Эксплойт:** используется в атаках
- **Идентификаторы:** CVE-2026-88771, CVE-2026-88772, BDU:2026-15496, BDU:2026-15497
- **CVSS:** 10 (AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:H)
- **Последствия:** Удалённое выполнение кода, получение root-доступа, установка веб-оболочек, кража учётных данных, возможный отказ в обслуживании.
- **Сверено по базам:** CVE-2026-88771: CISA KEV с 27.09.2026; BDU:2026-15496, эксплойт существует, используется в атаках; CVE-2026-88772: CISA KEV с 27.09.2026; BDU:2026-15497, эксплойт существует в открытом доступе, используется в атаках

**Почему важно:** Необходимо немедленно установить патчи Citrix, иначе подстанции могут быть скомпрометированы через уязвимый NetScaler.
