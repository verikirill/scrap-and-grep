# Свои источники вне датасета

Ассистент читает не только свой каталог: любой адрес сайта, раздела новостей, ленты или Telegram-канала определяется, попадает в каталог и опрашивается сразу. Здесь 14 адресов, которых нет в датасете организаторов, собраны 4 октября 2026 года одной командой консоли:

```bash
docker compose run --rm cli digest --sources /out/custom/sources.txt --audience specialist --days 3 --out /out/custom
```

Файл адресов кладётся в `./out/custom/` репозитория, контейнер консоли видит эту папку как `/out/custom/`.

- [sources.txt](sources.txt) - адреса с пометкой, какой это тип;
- [run.txt](run.txt) - вывод консоли: как определён каждый адрес и сколько публикаций прочитано;
- [specialist-3d-20261004-1746.md](specialist-3d-20261004-1746.md) и [.docx](specialist-3d-20261004-1746.docx) - выпуск специалисту по ИБ АСУ ТП за 3 дня по этим источникам.

Прогон шёл в отдельной базе стенда (`radar migrate --seed` без снимка публикаций), поэтому в выпуск попали публикации только этих источников. Модель - `gpt-oss:120b` в облаке Ollama, поиск по смыслу - `embeddinggemma:300m`. Образ стенда собран из `0f5437f`, до слияния `feature/more-sources`: в `main` у определителя и лестницы другие формулировки пометок (например, «отпечаток Chrome» вместо «curl_cffi»), а логика та же. В той же ветке четыре адреса отсюда (The Record, Help Net Security, Infosecurity Magazine, Security Affairs) вошли в каталог по умолчанию; в каталоге стенда на момент прогона их не было.

В выпуск вошли 6 записей из трёх источников: атака группы Longlegs через SharePoint (Security Affairs), уязвимости FortiMail, Zammad и GitLab AI Gateway, ИИ в поиске уязвимостей и операция против KillSec. Остальные 44 кандидата перечислены в конце выпуска, в блоке «Не вошло в выпуск», с оценкой и причиной: 40 из них ниже порога релевантности профиля инженера АСУ ТП, остальные объединены как пересказы одной новости или попали под исключение профиля.

## Что видно по прогону

- Защита главной страницы не мешает, если лента открыта: у GBHackers главная за Cloudflare отвечает боту 403, а лента `/feed/` читается обычным запросом. BI.ZONE за QRATOR отказал обычному запросу и прочитан с заголовками браузера, UserGate отдаёт пустую страницу-приложение и прочитан браузером стека.
- Неверный адрес не ломает прогон: so-ups.ru ответил 404, строка с отказом в выводе, остальные адреса прочитаны.
- Строка консоли пишет способ, которым ответила первая страница при определении: у UserGate там «plain», а читается он браузером стека. Ступень в таблице выше взята из каталога после опроса.
